small-things

browser playgrounds

Small TypeScript clients for small web services. Each module works in Node.js ≥ 22 and in the browser, ships a CLI and tests, and has a no-build playground page — served straight from this directory, transpiled in the browser with module-tsx and styled with sheerly.

0pw
signed storage

Up to 64 KiB of signed data per ed25519 key on 0pw.me — last write wins, storing null deletes. The playground also speaks 1pw.me's encrypted password format end-to-end.

foundas
found.as publisher

Publish pages on found.as through the be.found.as API. The same address + password as the official editor, every page type (redirect, markdown, HTML, file, contact), and custom domains.

libk
dynamic DNS

Claim a libk.org subdomain, protect it with a password, and point it at one or more IPs — first come, first served. Password rotation included.
